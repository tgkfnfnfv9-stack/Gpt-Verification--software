# GPT 戦略検証ビューア

ChatGPTや検証エンジンが出力したJSONを、ブラウザで確認する静的HTMLビューアです。バックテストの実行・戦略編集・発注は行いません。

## 使い方

1. `index.html` をブラウザで開きます。初期状態はデータなしです。
2. 「JSONを追加」で1個または複数のJSONを選択します。ドラッグ＆ドロップにも対応します。
3. 読み込み済みデータと銘柄・時間足のタブで表示を切り替えます。
4. トレード一覧をクリックすると、該当エントリーへ移動します。「← 前」「次 →」「時間全体」でも表示を変更できます。
5. データの「消す」で1ファイル分、チャートの「×」で1チャート分、「すべて消去」で全データを画面から削除します。元のJSONファイルは削除されません。「すべて消去」は読み込み中・待機中の追加も取り消します。

読み込んだJSONはブラウザのメモリで処理され、サーバーへ送信されません。ページの再読み込み・終了で読み込み状態は失われます。APIキー・アカウント・サーバー側プログラムは不要です。PCではホイールでズーム、ドラッグで横移動できます。スマートフォンでは次の2つの表示を使い分けられます。

### 通常画面（初期状態）

- チャート上でも上下スワイプはページのスクロールになります。斜めの操作も縦移動を優先します。
- 横方向が明確な1本指スワイプはチャートの横移動になります。
- 時間軸の拡大・縮小は「＋時間」「－時間」、全期間に戻すには「時間全体」を押します。価格軸は連動して変わりません。
- 2本指の操作はブラウザのページズームに任せます。チャート自体のピンチ操作には「全画面」を使ってください。

### 全画面チャート

- 「全画面」で、ブラウザの表示領域いっぱいにチャートを開きます（OSのフルスクリーンAPIは不要です）。
- 1本指で横移動、2本指を広げると時間軸だけ拡大、狭めると時間軸だけ縮小できます。価格軸は固定です。下部の時間軸ボタンも使えます。
- 上部の「閉じる」は常に表示されます。PCではEscキーでも閉じられます。
- 閉じると元のページ位置に戻り、チャートの表示位置・拡大率は維持されます。
- 全画面中は背面ページのスクロールを止め、閉じると元に戻します。

全期間表示中は横移動できる余地がないため、先に拡大してください。トレード一覧と前後ボタンによる移動も利用できます。

## 時間軸と価格軸を独立して操作

- 価格の自動拡縮はしません。最初の表示時にだけ価格範囲を決め、その後は横移動・時間ピンチ・時間ボタン・トレード選択でも固定します。
- **右端の価格目盛り**を上にドラッグすると縦に拡大、下にドラッグすると縮小します。通常画面・全画面の両方で使えます。価格目盛り以外の通常画面では上下スクロールを維持します。
- **「価格を合わせる」**は、表示中のローソク足に価格範囲を一度だけ合わせます。自動追従をONにするボタンではありません。
- 価格目盛りはキーボードでも操作できます。Tabで選び、↑/↓で拡縮、Homeで価格範囲を合わせます。
- **「時間全体」**は全期間を表示するだけで、価格範囲は変更しません。
- チャート/データの切り替え、全画面の開閉、画面回転でも、チャートごとの時間・価格の表示範囲を保持します。ページを再読み込みするとリセットされます。
- 初回読み込み時は全期間を表示し、最初のトレードへの自動拡大は行いません。トレード選択は時間方向の移動だけで、拡大率は保ちます。

## 表示できるもの

- 複数銘柄・時間足のローソク足
- 価格上の線・バンド、別枠の線・ヒストグラムなど複数インジケータ
- 買い・売り、選択トレードのエントリー・決済・損切り・利確位置
- トレード一覧、戦略仕様、検証メモ
- トレード数、勝率、期待値、PF、最大DD、累積R

集計対象は選択中のJSON全体です。チャート切り替え・一覧フィルターでは上部の全体成績は変わりません。チャートを削除すると、そのチャートのトレードを除いて再計算します。

## 指標の意味と制限

`r` は各トレードの損益を初期リスクの何倍かで表した値です。ビューアは入力済みの `r` を集計し、約定価格・手数料から再計算しません。

| 指標 | 計算方法 |
|---|---|
| 勝率 | `r > 0` の件数 ÷ 全件数（引分を含む） |
| 期待値 | `r` の合計 ÷ 全件数 |
| PF | 正の `r` の合計 ÷ 負の `r` の絶対値の合計。利益のみなら∞、全件ゼロなら0 |
| 最大DD | `trades` の配列順に累積したRのピークからの最大下落幅 |
| 累積R | `r` の合計 |

最大DDは金額・パーセント・含み損を含む資産曲線のDDではありません。時系列で評価する場合は、JSON作成側でトレードを決済時刻の昇順に並べてください。BUY・SELL別集計は内部で計算されますが、専用成績カードはありません。

欠損・不整合のOHLC、不正なオブジェクト構造、有限数でないRはファイル単位でエラーにします。同時に選択した正常なファイルは読み込めます。

不明なチャートIDや範囲外の足番号などを補正する実装のため、厳密なデータ検証ツールとしては使用しないでください。入力JSONの正しさは生成側でも確認してください。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `index.html` | GitHub Pagesのトップページ |
| `report.html` | `index.html` と同一内容のビューア |
| `GPT出力JSON_仕様.md` | 入力JSONの形式・インジケータの指定方法 |
| `GPT用_出力指示.md` | ChatGPTへ渡す出力指示 |
| `プロジェクト指示書.md` | 全体方針と開発フェーズ |
| `Work_GitHub書き込み依頼書.md` | リポジトリへの反映要件 |

サンプルは自動表示されません。必要な場合だけ「JSONを追加」から読み込んでください。複数JSONの確認では、サンプルを複製して別名の2ファイルを選択できます。

## GitHub Pagesで公開

対象リポジトリ：`tgkfnfnfv9-stack/Gpt-Verification--software`、ブランチ：`main`。

リポジトリの **Settings → Pages → Build and deployment** で以下を設定します。

- Source：**Deploy from a branch**
- Branch：**main**
- Folder：**/(root)**
- **Save** をクリック

デプロイ成功後の想定URL：<https://tgkfnfnfv9-stack.github.io/Gpt-Verification--software/>

公開後はトップページ、日本語UI、複数JSON追加、個別・全削除、チャート・指標・一覧、スマートフォン表示を確認してください。

## 安全性

公開リポジトリと公開ページに置くファイルは誰でも閲覧できます。APIキー、GitHubトークン、MT5やブローカーの認証情報、個人情報を含むログ・実口座データをコミットしないでください。サンプルは表示確認用であり、投資成績や戦略の有効性を示しません。


## 開発時のテスト

Node.js 18以降で、リポジトリ直下から実行します（追加パッケージ不要）。

```sh
node --test tests/chart-interactions.test.cjs
```

実際のHTMLに登録されたPointer Eventsを簡易DOM・Canvas環境で呼び出し、スライド、ピンチ、端の制限、操作中断、マウス操作とJSON操作の回帰を確認します。実ブラウザのイベント配送やCSSの動作を再現するテストではありません。通常画面の縦・斜めスワイプ、横移動、全画面でのピンチ、閉じる/再表示、元のスクロール位置への復帰、画面回転も検証対象です。価格軸固定、価格目盛りの操作、チャート別の範囲保持、読み込みの競合・取り消し、不正JSON、指標のゼロ基準も検証します。実機のiOS Safari・Android Chromeでも確認してください。
